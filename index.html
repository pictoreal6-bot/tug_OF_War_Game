🏆 Tournament Manager

League matches, knockout matches and the final each have their own question set. Create or edit the questions for every match, then use Play to record the result automatically.

How matches work

Each fixture has its own questions. Use Create Game to build them, Edit to change them later, and Play to run that exact fixture. When both teams finish, the score is recorded automatically and the points table / next knockout round updates.
